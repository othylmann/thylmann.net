# thylmann.net

Oliver Thylmann's personal site. A static Astro site deployed to GitHub Pages at https://thylmann.net.

## Stack

- Astro 7 (static output), Tailwind CSS 4 via the Vite plugin, TypeScript
- `@astrojs/sitemap` generates `sitemap-index.xml` on build; don't hand-write sitemaps
- `rss-parser` for build-time feeds, Vitest for unit tests
- Node 24 in CI (bundles npm 11). Lockfiles written by npm 11 fail `npm ci` on npm 10, so keep local npm at 11+

## Commands

```sh
npm install
npm run dev       # local dev server
npm run build     # static build to dist/
npm test          # vitest (watch); use `npx vitest run` for a single run
```

Run `npx vitest run` and `npm run build` before committing.

## How content gets in

Everything external is fetched **at build time**, never in the browser. Each fetcher catches its own errors and returns empty/null so a dead source never breaks the build; the matching section just disappears.

| Source | File | Used by |
|---|---|---|
| Substack blog (`blog.thylmann.net/feed`) | `src/utils/blog.ts` | Home "Latest Writing", `/llms.txt` |
| Die Nerd Show feed (Riverside RSS) | `src/utils/podcast.ts` | Hero |
| Goodreads RSS | `src/utils/books.ts` | `/books` |
| Discogs API | `src/utils/discogs.ts` | `/vinyl` |
| Quotes | `src/data/quotes.md` (one per line, `Quote - Author`) | Hero |
| Ventures timeline | `src/content/ventures/*.md`, schema in `src/content.config.ts` | `/about` |

`DISCOGS_TOKEN` comes from GitHub secrets in CI. Locally it's usually unset, so Discogs returns 403 and `/vinyl` builds empty; that's expected.

## Identity data: single source of truth

`src/data/person.ts` holds the profile links, press list, companies, podcast, blog and all schema.org JSON-LD. The layout's `rel="me"` links, the About page and `/llms.txt` all read from it. When adding a profile, press item or company, change it there and nowhere else. Keep it consistent with LinkedIn, giantswarm.io and Wikidata (Giant Swarm is Q141753589); Google only builds a knowledge panel when they agree.

## Agent entry points

- `/llms.txt` is generated by `src/pages/llms.txt.ts` from `person.ts` plus the latest blog posts. New pages should be added to its "Pages" list.
- `BaseLayout.astro` advertises the blog RSS feed and `/llms.txt` via `<link rel="alternate">`.
- `public/robots.txt` points to the sitemap.

## Deploy

`.github/workflows/deploy.yml` builds and deploys on every push to `main` and nightly at 00:00 UTC, so new blog posts, books and records show up within a day without a commit. There's no staging; `main` is live.

## Conventions

- Pages in `src/pages/`, components in `src/components/`, fetchers in `src/utils/` with a `*.test.ts` next to them (mock `rss-parser` as in `podcast.test.ts`).
- External links: `target="_blank" rel="noopener noreferrer"`.
- Design tokens live in `src/styles/global.css`; reuse existing classes (`glass-card`, `text-accent`, `font-mono` labels) instead of new colors.
- Site copy is English.
- Commit messages: `type: summary` (`feat`, `fix`, `chore`, `design`, `schema`, `about`).
- `dist/` and `.agent/` are gitignored. iCloud sometimes creates `name 2.ext` duplicates; delete them, never commit them.
